# Lesson 3 – TorchScript Inference Service

## Структура каталогу

- `install_dev_tools.sh` – ідемпотентний скрипт установки Docker, Docker Compose, Python 3.10+ та ML-залежностей.
- `export_model.py` – експортує `torchvision.models.mobilenet_v2` у формат TorchScript (`model.pt`).
- `inference.py` – inference-сервіс із CLI, показує top-3 класи.
- `Dockerfile.fat` – одностадійний образ (>1 GB).
- `Dockerfile.slim` – multi-stage образ з мінімальним рантаймом.
- `report.md` – порівняння образів і висновки.

## 1. Підготовка середовища

```bash
chmod +x lesson-3/install_dev_tools.sh
./lesson-3/install_dev_tools.sh
```

Скрипт логуватиме дії у `install.log` і перевірить версії Docker / Python / ML-бібліотек.

## 2. Експорт моделі

```bash
cd lesson-3
python export_model.py --output model.pt
```

Опційно задайте `--device cuda`, якщо маєте GPU.

## 3. Локальний inference

```bash
python inference.py --image path/to/image.jpg
```

Буде виведено top-3 передбачення з ймовірностями та переконаєтесь, що `model.pt` валідна до контейнеризації.

## 4. Збірка Docker-образів

```bash
docker build --no-cache -t lesson-3-fat -f Dockerfile.fat .
docker build --no-cache -t lesson-3-slim -f Dockerfile.slim .
```

Поточні розміри (CPU-only PyTorch 2.2.1):

- `lesson-3-fat`: ~1.88 GB (python:3.10-slim + системні пакети)
- `lesson-3-slim`: ~1.37 GB (multi-stage builder, без build-інструментів у рантаймі)

## 5. Запуск контейнерів

Передайте шлях до зображення через volume:

```bash
docker run --rm -v $(pwd)/lesson-3:/data lesson-3-fat --image /data/test_image.jpeg
docker run --rm -v $(pwd)/lesson-3:/data lesson-3-slim --image /data/test_image.jpeg
```

У репозиторії вже є `lesson-3/test_image.jpeg`. За потреби підмінить його власним файлом та скоригуйте шлях.
